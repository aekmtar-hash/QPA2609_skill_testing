# 射频测试板统一设计标准（草案 v0.9）

| 项目 | 内容 |
|---|---|
| 适用范围 | 组里所有射频单器件测试板：滤波器 MFBP-00144CSP3、LNA/PA QPA2609、移相器 MAPS-010166、隔离器 HMITE80T120G 等；以后的整条链路板也按这个来 |
| 基准板 | QPA2609 测试板（进度最快，第 6 章已完成，DRC 电气项全为 0） |
| 状态 | **草案**。叠层还没让板厂确认，确认后改成 v1.0 |
| 起草日期 | 2026-10-19 |

所有数字都来自 QPA2609 测试板的实际设计（AD 截图、《设计全过程讲解_20261017》），每一项后面写了依据。

---

## 0　为什么要统一

**最终的整板 = 把各块测试板去掉 SMA 连接器，按链路顺序直接连起来。** 所以每块测试板其实是整板的一个"模块"，测试板测出来的性能，要能原样代表它在整板里的表现。要做到这一点：

1. **板子之间要能接。** 叠层、线宽一样，一块板的 50 Ω 线和下一块板的 50 Ω 线才能直接对上；叠层不一样，接上就是阻抗台阶，整板和测试板就不一样了。
2. **线宽是由叠层算出来的。** 射频介质的材料和厚度定了，50 Ω 的线宽就只有一个答案。所以统一的核心是**统一叠层**，线宽跟着统一。
3. **连接器是由板厚决定的。** 总厚统一，全组才能用同一种 SMA 连接器、同一套封装，测试条件一样，数据才能直接比。
4. **切口要事先定好。** 测试板上哪一段是"模块"（拼板时整块搬过去），哪一段是"连接器过渡段"（拼板时删掉），要全组用同一个定义，见 1.8。

## 1　指标总表

**强制**：每块板都必须照做，不一样要先在组里说明理由。**建议**：最好照做，按器件情况可以调整。

### 1.1　叠层和板厚（强制）

| 层 | 材料 | 厚度 | 作用 |
|---|---|---|---|
| Top | 铜 1 oz | 0.036 mm | 射频线、全部器件 |
| 介质 1 | **Rogers RO4003C**（Core），Dk 3.55，Df 0.0027 | **0.203 mm**（8 mil） | 射频介质，**决定线宽** |
| GND2 | 铜 1 oz | 0.036 mm | **完整地平面**，射频线的参考地 |
| 介质 2 | FR-4（半固化片） | 0.200 mm | 凑厚度 |
| GND3 | 铜 1 oz | 0.036 mm | 地 |
| 介质 3 | FR-4 | 1.000 mm | 凑厚度 |
| Bottom | 铜 1 oz | 0.036 mm | 地，连接器下脚焊这一面 |
| **成品总厚** | | **1.566 mm**（AD 显示 61.636 mil，含两面阻焊） | 连接器要求 0.062 in = 1.57 mm |

- 表面处理：沉金（ENIG）。
- 依据：Cinch 142-0761-851 是给 0.062 in 板设计的，要求高频介质 0.008～0.014 in（Cinch 手册第 6 页）；射频层和 Qorvo 官方评估板一样，都是 0.203 mm RO4003C。

### 1.2　阻抗（强制）

| 指标 | 要求 |
|---|---|
| 射频线类型 | 顶层单端微带线，参考 GND2 |
| 特性阻抗 | **50 Ω** |
| 设计核算 | AD 阻抗计算：W = 0.417 mm 时 50.01 Ω（盖阻焊）。射频线开窗不盖阻焊后，公式重算约 50.4 Ω，差不到 1 Ω |
| 板厂制造 | 下单写"顶层单端 50 Ω 阻抗控制"，公差按板厂能力（常见 ±10%，这是经验值） |

### 1.3　射频线宽和走线（强制）

| 指标 | 要求 | 依据 |
|---|---|---|
| 主线宽 W | **0.417 mm** | AD 阻抗计算 |
| 线边到同层地铜 G | **≥ 1.0 mm** | 1.0 mm 约是介质厚的 5 倍，地铜基本不影响阻抗；官方板约 1.6 mm，改成 1.0 阻抗约差 1 Ω |
| 线下方 | GND2 整层不挖空，射频线下面不走任何别的线 | 参考地完整，阻抗才是算出来的那个数 |
| 走法 | 尽量一根直线，器件射频脚和连接器中心对在同一条水平线上 | 少拐弯，少一处阻抗变化 |
| 器件引脚前收窄 | 宽线一直拉到引脚焊盘跟前，**最后约 0.3 mm 才收窄到引脚焊盘宽度** | 细线不是 50 Ω（0.25 mm 宽约 67 Ω），细段越短反射越小；官方板就是这么做的 |
| 连接器焊盘 | 用 Cinch 推荐的 0.406 mm，不改 | 和 0.417 只差 0.011 mm |

> 统一的是"50 Ω 主线 0.417"这一个宽度。每颗器件引脚宽度不一样，所以收窄宽度跟着各自器件的引脚走，这是允许的，但收窄段要尽量短。

### 1.4　射频连接器（强制）

| 指标 | 要求 |
|---|---|
| 型号 | **Cinch 142-0761-851**（板边焊接式 SMA，0～26.5 GHz） |
| 封装 | 用 QPA2609 测试板改过的那份库：补了两块接地焊盘（3.61 × 5.664 mm，X = ±2.262）和 GND 引脚 |
| 摆放 | 封装原点在板边以内 **2.97 mm** |
| 接地孔 | 每只 8 个，孔 0.4 / 焊盘 0.7，照 Cinch 手册"16 mil 孔、50 mil 间距" |
| 底层 | 连接器正下方底层开阻焊窗 5.54 × 8.14 mm，下脚焊在底层地上 |

### 1.5　接地、过孔和铺铜（强制）

| 指标 | 要求 | 依据 |
|---|---|---|
| 铺铜 | Top、GND2、GND3、Bottom 四层都铺 GND；Solid 实心；Pour Over All Same Net Objects；勾 Remove Dead Copper | 整片地，没有孤立铜块 |
| 焊盘连地铜 | Direct Connect（整片连接，不用十字花） | 射频接地要整片 |
| 射频线屏蔽孔 | 孔 0.25 / 焊盘 0.5，线两侧各一排，**离线中心 1.61 mm，间距 ≤ 0.6 mm** | 14 GHz 时板材里波长的 1/20 ≈ 0.57 mm；官方板 0.554 mm |
| 缝合孔 | 孔 0.25 / 焊盘 0.5，大片地铜上 1.5 mm 网格、隔行错开 | 官方板孔距中位数约 1.5 mm |
| 缝里不许有孔 | 打缝合孔时临时加规则"射频网络 ↔ 过孔 ≥ 1 mm"，打完删掉 | 孔进了 1 mm 的缝会改变阻抗 |
| 器件中心焊盘过孔 | 照各自器件手册或官方评估板；能不能塞孔看板厂 | QPA2609 板不塞孔时用 5 × 5，间距 0.55 |
| 去耦电容接地孔 | 焊盘旁留约 0.3 mm 缝，再用 0.3 mm 短线连到过孔 | 防止锡顺着孔流走 |

### 1.6　阻焊（强制）

| 指标 | 要求 | 依据 |
|---|---|---|
| 射频线 | 线和两侧的缝**开窗不盖绿油**，开窗带取线中心上下各 2.0 mm，停在离器件中心约 2.4 mm 处（碰不到引脚） | Cinch 手册第 8 页 f 条；官方板阻焊 Gerber |
| 过孔 | 全部盖油（规则 Via_Tent：IsVia，顶底都勾盖油） | 防止吸锡和焊接短路；射频带、焊盘里的孔仍然露铜 |

### 1.7　AD 设计规则（强制，照抄）

| 规则 | 设置 |
|---|---|
| Clearance（默认） | 0.15 mm |
| RF_to_Pour（新建） | 第一对象 `InNet('RFIN') OR InNet('RFOUT') OR InNet('THRU')`，第二对象 `InPolygon`，≥ 1.0 mm，优先级高于默认 |
| RF_Width（新建） | 射频网络：最小 0.2 / 首选 0.417 / 最大 0.417 mm |
| Width（默认） | 0.15 / 0.3 / 1.5 mm（直流线用 0.3） |
| Routing Via Style | 直径 0.5～0.7，孔径 0.25～0.4 mm |
| Polygon Connect Style | Direct Connect |
| Via_Tent（新建） | `IsVia`，顶层、底层都盖油 |

射频网络名统一叫 **RFIN、RFOUT、THRU**，规则可以直接照抄，不用改条件。器件的射频口多于两个时，在规则条件里把新网络名加进去。

### 1.8　模块接口：拼成整板的关键（强制）

把每块测试板分成三段：

```
测试板：  [SMA + 过渡段] ──┤ 接口面 ├── 模块区（器件 + 周边全部） ──┤ 接口面 ├── [过渡段 + SMA]
                删掉                           整块搬到整板                            删掉

整    板：  SMA ── 模块A ──50Ω线── 模块B ──50Ω线── 模块C ── … ── SMA（只在整条链路两头留连接器）
```

| 指标 | 要求 | 说明 |
|---|---|---|
| 接口面位置 | **离板边 6.00 mm**（连接器区结束、第一对屏蔽孔处） | QPA2609 板：输入接口面 X = 6.00，输出 X = 19.40，离芯片中心各 6.70 mm。连接器金属脚只到离板边 4.55 mm，6.00 以内就不受连接器影响 |
| 接口面上的线 | 必须是标准线：0.417 宽、两侧 G = 1.0、屏蔽孔照 1.5 排 | 两块模块在接口面对接，线就是一根连续的 50 Ω 线，没有台阶 |
| 模块区内容 | 器件、去耦电容、中心焊盘过孔、收窄段、屏蔽孔、阻焊开窗，**整板上按相同相对坐标照搬，一个都不改** | 照搬了，测试板测出来的才代表整板里的它 |
| 射频方向 | 输入在左、输出在右，射频线是**一条水平直线**，进出口在同一高度 | 整板上各模块排成一行，按射频线对齐就能直接连 |
| 直流和控制线 | 只从模块的**上、下两边**引出，不许横穿射频线 | QPA2609 板：VD 往上、VG 往下。整板上在上、下两边走公共电源线 |
| 射频通路里的元件 | 整板上射频通路里要有的元件（比如隔直电容），**测试板上必须也有，位置一样** | 测试板少了，整板多了，测出来的就对不上。QPA2609 片内有隔直电容，不用外加；其他器件按各自手册查 |
| 直通校准线 | 每块测试板都要有（这一条从"建议"升为强制） | 用它扣掉 SMA 和过渡段，得到模块区本身的数据；还能量出 0.417 线每毫米的损耗，整板上模块之间连线的损耗就能算出来 |
| 坐标记录 | 每块板交一张表：器件中心坐标、两个接口面坐标、射频线的 Y 坐标 | 拼整板时照表摆放 |

> 移相器 MAPS-010166：按 24 脚 QFN 的标准排脚推算，RF IN（5 脚）和 RF OUT（14 脚）应该在同一高度，能走直线。这是我按引脚编号推的，没有对过封装图，画之前请用它的封装核对一下。

### 1.9　建议项

| 项目 | 建议 | 理由 |
|---|---|---|
| 直流供电接口 | 暂时用单针端子；等供电板方案定了，全组统一插座型号和针脚定义 | 见 `5_供电\QPA2609供电说明.md` |
| 丝印 | 电源端子旁写清电压和极性（如"VD +3.5V""VG 负压"） | 防止上电接反 |

## 2　怎么在 AD 里做到这些指标

下面每一步都是 QPA2609 板上已经做过、在你截图里确认过的操作。

### 第 1 步　填叠层（对应操作手册第 4 章）

1. 打开 Layer Stack Manager，加到 4 层铜，改名 Top / GND2 / GND3 / Bottom。
2. 照 1.1 的表填每层：介质 1 的 Material 格直接打字 `RO4003C`，Thickness `0.203mm`，Dk `3.55`，Df `0.0027`，Type 改成 Core。其余照表填。
3. **取消 Stack Symmetry（对称）**，否则改一层会连带改别的层。
4. 看底部总厚：应该是 **61.636 mil（1.566 mm）**。

### 第 2 步　算线宽，自己核对（对应第 4 章）

1. Impedance 标签页左上角 **+ Add**，建一个配置：Single，Target 50 Ω。
2. 看 Top Layer 那一行（Bottom Ref 选 GND2）的 Width：**应该是 16.422 mil = 0.417 mm，阻抗 50.01 Ω**。

> **这一步就是自检。** 算出来不是 16.422 mil，说明叠层哪一格填得和标准不一样，回第 1 步逐格对表。不要直接改线宽去凑。

### 第 3 步　建规则（对应第 6 章 6.1）

照 1.7 的表逐条建。RF_to_Pour 建好后点"测试语句"，能选中射频网络上的焊盘和线，说明条件写对了。

### 第 4 步　画射频线（对应第 6 章 6.2）

1. `Ctrl+W` 交互布线，按 `Tab` 把线宽设成 0.417。
2. 从连接器焊盘中心水平拉到器件引脚焊盘跟前（离引脚中心约 0.3 mm）。
3. 再按 `Tab` 把线宽改成该器件引脚焊盘的宽度，接到引脚中心。

### 第 5 步　过孔、铺铜、阻焊（对应第 6 章 6.5～6.11）

照 1.4～1.6 的表做，顺序：器件中心过孔 → 电容接地孔 → 连接器接地孔 → 屏蔽孔 → 四层铺铜 → 缝合孔（先加临时规则）→ 阻焊开窗和 Via_Tent。

### 第 6 步　出图前自查

| 检查项 | 合格标准 |
|---|---|
| 叠层总厚 | 61.636 mil |
| Impedance 里 Top Layer 的 W | 16.422 mil / 50.01 Ω |
| 射频线宽 | 主线 0.417，只在引脚前约 0.3 mm 收窄 |
| 射频线两边的缝 | 顶层铺铜离线 1.0 mm，缝里没有过孔 |
| GND2 | 射频线下面整片铜，没有挖空 |
| 阻焊 | 射频带开窗，过孔盖油 |
| 连接器 | 型号 142-0761-851，原点离板边 2.97 mm，每只 8 个 0.4 孔 |
| 接口面 | 离板边 6.00 mm 处，线是 0.417、两侧 G = 1.0、屏蔽孔连续 |
| 射频方向 | 输入在左、输出在右，一条水平直线；直流和控制线只从上、下两边出 |
| 坐标表 | 器件中心、两个接口面、射频线 Y 坐标都记下来了 |
| DRC | 短路、没连上、间距、线宽、孔径全部为 0 |

## 3　板子回来以后怎么验收

所有板子用同一套方法测，数据才能比：

1. **先测直通线 J7–J8**：存一份 s2p。10 GHz 附近回损好于 15 dB 算正常（这是经验值）。直通线就不好，说明问题在连接器那一段或线宽，不在器件。
2. **再测器件**：网分 8～12 GHz，二端口校准，源功率按各器件手册设，不超过器件输入极限。
3. **扣掉连接器和走线**：用直通线的损耗按长度比例修正，结果和器件手册的 S 参数比。

## 4　拼成整板时，测试板验证不了的事

参数全部统一以后，模块能接上，单个模块的性能也能代表整板里的它。但下面几件事只有整条链路接在一起才会出现，测试板测不出来，整板设计时要另外考虑：

| 问题 | 为什么测试板看不到 | 怎么应对 |
|---|---|---|
| 级间失配 | 测试板是接在 50 Ω 仪器上测的；整板上前一级的输出反射会碰到后一级的输入反射，在中间来回，增益曲线会出现起伏 | 把各块测试板实测的 s2p 在 ADS 里按顺序串起来仿真，就能看到这个效应 |
| 自激振荡 | 两颗 QPA2609 各约 26 dB 增益，放在一块板上，输出的一点点能量漏回输入就可能振荡 | 前后级拉开距离、屏蔽孔做成连续的"墙"，必要时加金属屏蔽罩；整板布局时专门检查 |
| 电源互相干扰 | 测试板每块单独供电；整板共用电源，一级的噪声会通过电源线串到别的级 | 每个模块保留自己的去耦电容（模块区照搬就保留了），公共电源再加滤波 |

## 5　变更怎么管

- 这份标准由 QPA2609 板维护。任何一项要改，先在组里说，再改这份文件，在下面记一笔。
- **板厂回复后必改的**：RO4003C 厚度或 Dk、铜厚变了，就在 AD 里重算 W，**全组同步改线宽**；总厚做不到 1.57 mm，要换连接器型号和封装。
- 板厂给了他们自己算的线宽，以板厂为准。

| 版本 | 日期 | 改了什么 |
|---|---|---|
| v0.9 草案 | 2026-10-19 | 按 QPA2609 测试板整理；加 1.8 模块接口和第 4 章拼板风险 |
