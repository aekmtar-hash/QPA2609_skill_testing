# 规划端工作流（主会话：想清楚、算坐标、自检、核对；不直接调 eda-agent）

## 0　先收集事实，不要凭印象

1. **现有设计状态**：元件、走线、过孔、开窗、规则、叠层、层名、原点、工程实际引用的文档。
   - **本机模式**（PcbDoc 就在这台电脑上）：
     - 文字、线、弧、过孔、板区域、元件序号：直接读文件，`python -I scripts/pcbdoc_io.py summary <PcbDoc>`；
     - 焊盘（格式复杂）和规则：派 Haiku 子代理导出（`subagent-prompts.md` 模板 2），再拿 DRC 报告里的焊盘坐标抽查；
     - 读文件前确认 AD 已经保存过，不然读到的是旧状态。
   - **远程模式**：先让执行端做一次只读侦察（`pcb_get_components`、`obj_query` 导出焊盘、过孔、线、区域的坐标 / 尺寸 / 形状 / 网络，规则和启用状态，工程实际引用的文档名），照真实数据规划。做不到就从用户的记录 / 截图建模，写明"按记录建模"，并且留的余量要大于建模误差。
   - QPA2609 只按记录建模，错了 3 处：J3～J6 的方焊盘当成了圆的；两个过孔差 0.13 mm；工程里挂的是 `_no3d` 副本。
   - 侦察到的**所有**铜都进模型（原有的供电线、地线、过孔），不要只建"受保护的"射频线。QPA2609 第二轮：缝合孔脚本没建原板的 VG 线，一个孔离它 0.025 mm。
   - 规则要记下**是否启用**。QPA2609 原设计里 Minimum Solder Mask Sliver 是 Disabled（0.254 mm），我写说明书时不知道。
2. **库的真实几何**：AD 的 .PcbLib / .SchLib / .IntLib 都是 OLE 复合文件，用 Python `olefile` 直接读。
   - **先跑一遍 `python -I scripts/pcblib_inventory.py <库文件夹> --texts`**：每个封装按"层 × 图元类型"列表，标出 Top / Keep-Out 层上的 region 和 Top Overlay 上的文字。前两轮漏掉的禁布区、`.Designator` / `REFDES` 文字都会被它列出来。
   - PcbLib：每个封装一个 storage，`Data` 流里按记录读（焊盘记录类型 2，有 6 个子记录；第 5 个子记录里偏移 13 起是 x、y、X 尺寸、Y 尺寸（int32，单位 1e-4 mil = 2.54e-6 mm），偏移 45 孔径，49 形状，52 是焊盘自身旋转（double）——**旋转 90/270 要交换 X/Y 尺寸**）。
   - Mech15 一般是 courtyard，Mech13 是本体（Ultra Librarian 的库）；没有就用焊盘外扩 0.25 mm 估。
   - **Region（记录类型 11）也要读**：第 1 个子记录的偏移 0 是层号（1 = Top，56 = Keep-Out），偏移 2 那个字节为 2 表示禁布区（keepout）；偏移 18 起是属性字符串的长度和内容，后面是顶点数和 double 坐标（单位 1e-4 mil）。QPA2609 漏过：SSA34（D101）有 3 块 Top 禁布区，BLM18AG（FB101/FB102）、APT1608（LED101）各有 Top 和 Keep-Out 各 1 块，离自己的焊盘只有 0.05 mm。实跑时 DRC 报了 26 条 Clearance，执行端只好把它们挪到 Mechanical 15。处理办法二选一：改库，或者在数据包里写一步"摆完后把这几块 Region 挪到 Mech15"。
   - 焊盘形状（偏移 49）：1 = 圆，2 = 矩形，3 = 八角。**通孔焊盘别默认当圆的**，插件元件的 1 脚常常是方的。
   - SchLib：二进制 pin 记录里能读出脚号、脚名、位置、方向，用来确认"1 脚在哪边""二极管哪边是负极"。
   - IntLib：子库是 zlib 压缩（去掉第 1 个字节再解），读出来确认自带库里的元件名、默认封装、封装焊盘尺寸。
3. **芯片手册**：每个引脚的功能、哪些脚必须接什么（例如 LT3094 底部焊盘是 IN 不是地；PGFB 不用时接 IN；LTC3260 的 RT 接地 = 500 kHz）。

## 1　布局方法

- 先定"区域"和"走廊"：例如供电区必须在切口之间；跨区信号走哪一层（QPA2609：VG 走 GND3，从芯片和第一个屏蔽孔之间的缝穿过）。
- 每颗芯片先画"引脚出线拓扑"：哪些脚同一侧、哪些网络会交叉。**单层走不通就早点决定用过孔跳线**（底层 / 内层），不要硬挤。
  - 常见：电荷泵飞跨电容跨芯片两侧 → 绕过 NC 脚那一端；PGFB 和 OUT 在芯片两侧 → 必须跳线；两个同网络脚中间夹着别的网络 → 考虑改接法（QPA2609：EN− 改接相邻的 LDO+，并论证上电顺序不变）。
- 设计改动（哪怕是为了布线）都要写进"和原方案不一样的地方"，讲清原来是什么、为什么改、为什么不影响功能。
- 线宽种类越少越好（默认 0.3 + 少量 0.5/0.8），执行端不用频繁改宽度。
- **缝合孔、丝印也是布局的一部分**，和元件、走线一样由规划端算出坐标（见第 5 节），不交给工具自动生成。

## 2　自检（每改一次都全跑）

脚本 `prender.py check()` 的检查项，缺一不可：

| 检查 | 要点 |
|---|---|
| UNPLACED / UNKNOWN | 网表里每个元件都摆了（QPA2609 就漏过 C110，checker 没报，因为只查了已摆的） |
| 间距 CLR | 同层不同网络；通孔对象（过孔、插件焊盘）算在所有层；**留余量**：规则 0.15 就按 0.2 查 |
| 连通 OPEN | 同网络对象按同层相交合并；整层铺地的网络，凡碰到该层的过孔 / 通孔视为连通 |
| 外形 COURT | courtyard 不重叠（AD 的 Component Clearance 会按 3D 本体查） |
| 区域 ZONE | 模块元件 courtyard 在切口之间 |
| 板边 EDGE | 铜离板边 ≥ 0.4 mm |
| 孔距 HOLE | 孔边到孔边 ≥ 0.25 mm |
| 阻焊桥 SLIVER | 两焊盘间隙 − 两边外扩（芯片 0.05、其他 0.1016），在 (0, 规则值) 之间就报 |
| 走线顺序 | 每根线的起点在它之前已存在（生成表格时检查"起点名字"是不是坐标空点） |
| 禁布区 KEEPOUT | 库 Region 禁布区与本元件 / 别的元件焊盘、走线、过孔的关系（或者明确写"执行端把它挪走"） |
| 丝印 SILK | 见第 5 节的数字：离丝印线 / 别的字 ≥ 0.30、离焊盘铜 ≥ 0.40、不落在元件上、离板边 ≥ 0.25 mm；**封装自带的 Top Overlay 线、弧、文字都算障碍** |
| 临时规则噪声 | 说明书里要用的临时规则（如 RF_to_Via），先算出它会被**原有**对象触发多少条，写进说明书 |

现有设计对象作为 FIXED 加入：它们之间不互查（真实板上已经 DRC 过），只查新对象和它们的关系。FIXED 要包括原有设计的全部铜，不只是射频线。

## 3　出图核对

用 matplotlib 按真实几何出图（走线用 shapely buffer 画真实宽度，不要用 linewidth 估），整体 + 分块放大看一遍。注意 `set_xticks` 会撑大坐标范围，放大图要先设刻度再设范围。

## 4　输出

**本机模式**：不打包。每一步的输出是"给子代理的任务说明"（`subagent-prompts.md`）+ 它要用的数据文件（期望清单 CSV、坐标表），放在工程 temp 文件夹里一个按轮次命名的子文件夹（例如 `temp\round3\`）。改文件用的脚本和生成的数据也放这里，做完挑通用的收进本 skill。

**远程模式**：
1. 人类版指南（md + html：可勾进度、点走线高亮、分段图）。
2. 执行端数据包（data-package.md 的全部文件）+ AGENT_GUIDE.md。
3. 压缩包：外部库一个、代理包一个。差量包只出一个 zip，说明书引用的文件全放进去，解压到空文件夹核对一遍。
4. 所有数字从同一个坐标源（如 `pmod.py`）生成，**不手抄**。
5. 给便宜执行模型：`ops.jsonl` / `ops.csv`（`export_ops.py`）+ `RUNBOOK_HAIKU.md`。
6. 说明书要自己再通读一遍查**互相矛盾**的地方。QPA2609 的说明书一边说"不准改 J3～J6"，一边在 P6 让改它们的孔径。

## 5　原理图坐标和丝印怎么算

- **原理图**（`sch_layout.py`）：
  - 从 SchLib 读出每个符号的脚端点和方向（`schsym.py`），按功能分组排成网格，单元格大小 = 符号外框 + 短线 + 标号空间；
  - 每个脚向外拉一段 200 mil 的短线，线端放网络标号，接地的放 GND 端口；
  - 自查两项：不同网络的端点不能重合；单元格不能重叠；
  - 输出每个脚端点的期望坐标，给执行端放完一个元件就自查（符号原点和想的不一样时，所有脚会差同一个偏移）。
- **丝印**（通用脚本 `scripts/silk_geom.py`，完整用法见 `examples/qpa2609/round3/silk_place.py`）：
  - 内容：小阻容的位号藏起来（挪 Mechanical13），只留关键件的位号；**封装自带的 Top Overlay 文字**（`.Designator`、`REFDES`、`RefDes`、`DES`）也挪走，只留 `*` 这类 1 脚标记；再加功能字（电源输入写电压和极性、地、各输出端、调节电位器、模块名）。字高 1.0 mm、线宽 0.16 mm，方向只用 0° / 90°。
  - 障碍物全部取自真实板子：Top Overlay 的线、弧、留下的字（`pcbdoc_io`），焊盘（子代理导出的 CSV），过孔，元件本体（每个元件的焊盘 + 自己的外框线取凸包）。
  - 合格条件（AD 23 DRC 实测能过：Silk to Silk 0.254、Silk to Mask 0.254、阻焊外扩 0.102）：

    | 条件 | 值 |
    |---|---|
    | 离丝印线、别的字 | ≥ 0.30 mm |
    | 离焊盘铜皮 | ≥ 0.40 mm |
    | 不落在任何元件上（装上会被盖住） | ≥ 0.10 mm |
    | 离板边 | ≥ 0.25 mm |
    | 模块里的字 | 整个在切口线之间 |
    | 位号 | 离自己（焊盘 + 外框）≤ 1.2 mm，并且比离别的元件近 0.3 mm 以上 |
    | 功能字 | 离所属端子 ≤ 1.5 mm |

  - 字宽：Stroke 字体平均 0.80 × 字高，宽字母（G N D M O U W）约 0.9。排的时候按 0.85，宽字母多的按 1.0。
  - 搜索：每个字从"设计时想放的位置"出发，在附近找最近的合格位置（0.05 mm 步长）；先排位号，再排功能字；压过孔只做扣分。放不下的单独出图看：常见原因是判定写得太死（例如"离自己焊盘 ≤ 1.2 mm"对大外框的电位器不成立 → 改成按焊盘 + 外框算）。
  - 出分块预览图逐块看（`examples/qpa2609/round3/silk_view.py`）。
  - 落地：开着丝印规则跑 DRC，`drc_report.py --texts` 只看新字，按结果再挪；最后把丝印规则关回原样（如果原设计是关的）。
  - 工具限制：eda-agent 转不了文字、藏不了位号（`pcb_set_text_visibility` 会卡死）。本机模式下改方向 / 挪属于元件的文字，用 `pcbdoc-direct-edit.md` 的办法；远程模式写好备选（藏 → 挪 Mech13；转不了 → 列给人手动转）。

## 6　拿到执行端反馈以后

完整步骤见 `checklists.md` 的 C 节，这里是要点。

1. 先读 AGENT_REPORT 的"偏离 / 跳过 / 人要确认"几节和日志里的 MISTAKE、DEVIATION，逐条分成四类：**我的数据错**、**执行端错**、**工具限制**、**说明书缺漏**；执行端临场换的办法另列，看有没有副作用。
2. "我的数据错"先在自检里**复现**（例如把方焊盘建模对，看自检能不能报出同样的 0.13 mm），再改坐标源，全部重新生成、重新自检。
3. 执行端在现场做的修正（比如挪了 0.03 mm）不一定要照搬，数据里按规则留足余量重新算。
4. 教训写回：AGENT_GUIDE / RUNBOOK / ops（QPA2609 用 `patch_after_run1.py`）；本 skill 的 `lessons.md`（经验）、`eda-agent-pitfalls.md`（工具的坑）、`examples/<项目>/README.md`（实跑记录）。
5. 给用户讲清楚：做成了什么；哪些是我的错、已经怎么改；执行端改了哪些地方要人去看；哪些事工具做不了，要人手动做。
