# 数据包规范（远程模式：规划端 → 另一台电脑上的执行端）

本机模式不需要整包，只用其中需要的表（期望清单、坐标表），格式照这里。样例见 `examples/qpa2609/data/`（全部真实数据表 + 逐表说明）。

原则：**执行端拿到的每个数字都能直接写进 AD，不需要它理解或换算设计意图。** 文字说明只解释"为什么"和"出错怎么办"。

文件都放一个文件夹，同时给 JSON（全集）和 CSV（每类一张，UTF-8 带 BOM，Excel 能直接开）。说明书里引用到的每个文件（包括上一轮的 RUNBOOK）都要在这个文件夹里，打成**一个** zip。

---

## 1　metadata（json 顶层 `meta`）

| 字段 | 例子（QPA2609） | 说明 |
|---|---|---|
| `units_note` | "*_mm 相对板左下角用户原点；*_mil = mm/0.0254" | 必写。eda-agent 用 mil |
| `board_mm` | [0, 0, 25.4, 108.5] | 新板框 |
| `cut_lines_x_mm` | [6.0, 19.4] | 模块化时的切口（模块内容必须在之间） |
| `calibration_refs` | U1 (12.70, 31.70) rot 0；J3 (19.73, 49.40)；J1 (2.97, 31.70) rot 90 | 现有设计里位置确定的元件，执行端用来算坐标偏移和验证角度方向。至少 3 个，最好不共线 |
| `expected_counts` | 新元件 47、新过孔 45、新线段 155、保留过孔 137、要删的缝合孔 333、要删的铺铜 4、网络 27 | 每个阶段的核对门槛 |
| 层名映射 | Top Layer / GND2=MidLayer1 / GND3=MidLayer2 / Bottom Layer | 用户在叠层里改过名的，要同时给用户名和 AD 内部名，并说明"第几个内层" |

## 2　components（元件表）

| 字段 | 说明 / 坑 |
|---|---|
| `designator` | 手工指定，不要让执行端自动编号 |
| `lib_file`、`lib_ref` | 自带库写明"(AD built-in)" |
| `footprint` | **库里的真实封装名**。AD23 自带库：英制 0402 = `0402`，英制 0603 = `1608[0603]`（名叫 `0603` 的是英制 0201！），0805 = `6-0805_N`，1206 = `C1206`，1210 = `C1210`，2512 = `RESC6332`，2.54 排针 = `HDR1X2`/`HDR1X3`，单针 = `PIN1` |
| `value` / `comment` | **只用 ASCII**：22R、604R、1R 1%、10uF 25V、GREEN |
| `x_mm, y_mm, x_mil, y_mil` | 元件 Location = 封装原点。注意不在中心的封装（3296W 原点在 3 脚；HDR 原点在 1 脚） |
| `rotation_deg` | AD 的 Rotation，逆时针为正 |
| `layer` | Top / Bottom |
| `outside_cut` | 测试用、拼整板时会被切掉的元件 |
| `pins[]` | 每个脚：脚号、网络、焊盘中心（mm）——后面核对用 |

两脚无极性元件要写清"1 脚接哪个网络"，并告诉执行端：位置对但两个焊盘网络对调时，**无极性元件转 180° 即可，有极性 / 多脚元件不能转，要回去改原理图**。

自带库元件的默认封装（`Res2` → `AXIAL-0.4`，`Cap` → `RAD-0.3`）必须换掉并删除默认的，要在数据包里写明。

## 3　nets（网表）

- `net → [位号-脚号...]`；空脚单独列（`no_connect`）。
- 跨页 / 跨原有设计的网络（例如新供电页的 `VD`、`VG`、`GND` 要连到射频页的同名网络）要明确写出来，并给出核对方法（编译后某网络应同时含 `J3-1` 和 `FB101-2`）。
- 脚号以库里的 Designator 为准（底部焊盘常叫 `EPAD`、`13`、`17`……逐个读库确认）。

## 4　pad_nets（焊盘期望表）

`designator, pin, net, x_mm, y_mm`。摆放后执行端读回每个焊盘的中心和网络，容差 0.01 mm。这一张表同时验证了：原理图连接、封装选择、坐标、旋转。

## 5　vias（过孔表）

`no, net, x, y（mm+mil）, hole, diameter`。网络必须填（无网络的过孔会被间距规则挡住，或造成"短路"）。

## 6　track_segments（走线段表）

`track_no, step, step_name, net, layer, width, x1, y1, x2, y2（mm+mil）`。
- 一根"走线"拆成多段，同一 `track_no`。
- **顺序**：每根线的起点必须是已存在的焊盘、过孔或之前画好的线（或原有设计的线）——规划端排好，执行端照顺序画即可。
- 层名用第 1 节的映射。
- 编号和人类版指南一致，方便人第二天对照。

## 7　polygons / rules

- 铺铜：网络、层、外形（矩形给两个角）、填充方式、Pour Over 方式、Remove Dead Copper、连接方式（规则）。
- 规则：只列"新增 / 修改"的，每条写名字、类别、查询语句、数值（mm + mil）、优先级要求；临时规则写明什么时候删。

## 8　keep_existing（保留清单）

改现有设计时最关键的一张表：
- 必须保留的对象（坐标级，如 137 个手放过孔：芯片中心 25、连接器 32、屏蔽孔 74、电容旁 6），
- 以及"除此之外的某类对象应该正好有 N 个、要删掉"（如 333 个缝合孔）。
执行端用"差集 + 数量必须相等"来删，比依赖某个"删除整组"命令可靠。
- 坐标最好从真实板子读出来。按记录建模会有误差（QPA2609 有两个过孔差 0.13 mm，执行端用 6 mil 容差才对上）；表里写清楚允许的容差。
- 后面任何阶段删对象，都要先用这张表 + 本次新增对象表排除。
- 差量包里这张表按**实际做成的坐标**写（QPA2609 第二轮：`required_vias_asbuilt.csv`，182 个 = 137 原有 + 45 第一轮新放，含执行端挪过 0.03 mm 的那个），容差 2 mil。

## 9　stitch_vias（缝合孔坐标表）

`no, net, x, y（mm+mil）, hole, diameter`，和过孔表一样。
- 每个孔规划端都检查过：离射频线、离别的网络的铜（**含原有设计的全部铜**）、离已有过孔、不压焊盘 / 外框 / 丝印。
- 这张表同时是"允许删除清单"：DRC 筛孔时只能删这张表里的孔，并给出上限（QPA2609：超过 20 个就停）。
- 说明书里写明临时规则预计会被原有对象触发多少条，执行端不要去动那些。

## 10　ops.jsonl（给便宜执行模型的逐条清单）

一行一个 JSON：`{"id":"P8-001","phase":"P8","op":"PCB_VIA","params":{...},"verify":"...","on_fail":"STOP"}`。
- `params` 里坐标用 `_mil` 后缀的就是 PCB 坐标（写入时加偏移）；不带后缀的 x/y 是原理图坐标（不加偏移）。
- `verify` 写成能量化判断的句子；`on_fail` 用有限几种取值，RUNBOOK 里逐个解释。
- 每阶段最后一条是 `SAVE_AND_LOG`（带 `marker`，例如 `P8 DONE`），续做时按 marker 找断点。
- 复杂操作（删缝合孔、清理新孔、ECO、焊盘核对不过）不要拆碎，写成一个 op，具体步骤写在 RUNBOOK 里。

## 11　schematic_layout.json / silk.json

- 原理图：`components[{designator, lib_ref, x, y, rotation_deg}]`、`wires[{ref, pin, x1, y1, x2, y2, net}]`、`net_labels`、`power_ports`、`no_connect_pins`，单位是图纸 mil。
- 丝印：`text_height_mm`、`stroke_mm`、`labels[{kind: designator|string, ref, text, x, y, rot}]`、`hide_designators[]`。坐标是板的 mm，`x,y` 是文字框左下角。
- 丝印还要写"做不到时怎么办"：`hide_fallback`（例如挪到 Mechanical13）、`rotate_fallback`（例如不转，列给人；或者放普通文字并在报告里列出来）。eda-agent 0.7.1 隐藏和转文字都做不到。

## 12　libs

外部库全部放进 `libs/`；`.SchLib` 已关联封装；3D 嵌在 `.PcbLib` 里（逐个确认，没有 3D 的写明）。原始下载版和工程里改过的版本要区分（例如 QPA2609 封装引脚宽度改过），不要让执行端覆盖。
