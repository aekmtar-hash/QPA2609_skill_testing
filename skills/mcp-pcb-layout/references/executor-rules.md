# 执行端规则（给 eda-agent 一类 MCP 代理）

两种用法：
- **远程模式**：连同项目数据包（`data-package.md`）一起交给另一台电脑上的代理；项目专属的数字放在项目的 AGENT_GUIDE / RUNBOOK 里。
- **本机模式**：写进每次派给 `eda-agent-operator` 子代理的任务说明（模板见 `subagent-prompts.md`），子代理定义里已有大部分规则。

工具层面的坑在 `eda-agent-pitfalls.md`。

## 0　全局规则

1. 开工前确认备份存在；没有就先复制整个工程文件夹。
2. 只做清单里写的操作；不做设计决定，不"优化"。
3. 只改本次新加 / 指定的对象；保留清单里的对象、叠层、原点、已有规则数值一律不动。
4. 文字只用 ASCII。
5. 每阶段：做 → 核对 → 保存 → 写日志。**核对不过就停，不保存**，写清楚现状。
6. 优先用 API 类工具（obj_* / pcb_* / sch_* / proj_*）；模拟键鼠的 UI 工具（app_click_menu 等）只在没有替代时用，用之前写日志。
7. 每个工具第一次用之前先看 `tool_guide`；有批量版本就用批量，单批 ≤ 30 个对象。
8. **删除任何对象之前**，先用保留清单 + 本次新增清单把"必须存在的对象"排除掉，核对数量正好等于期望才删；删完数一遍，必须存在的一个都不能少。（第一轮修孔距报错时误删了 14 个原有屏蔽孔。）删除被权限系统拦下时停下汇报，不换办法绕过。
9. 改的是**工程实际引用的文档**（`proj_list_documents`），写进日志第一段；和说明书不一样就报告。
10. 没实测过的修改类工具：先保存，再拿一个对象试。
11. 汇报里把"工具读回的事实"和"自己的推断"分开写。

## 1　日志与断点续做（远程模式）

`AGENT_LOG.md`（工程文件夹）每阶段一段：

```
## P8 过孔  2026-10-20 23:41
- 计划 45 个；本次新放 45；跳过（已存在）0
- 核对：按 vias.csv 读回 45/45 位置误差 < 0.01 mm，网络一致
- 进度标记：P8 DONE
```

**续做**：每次开始先读日志，跳到第一个没有 DONE 的阶段。阶段内部：创建每个对象前先查"同坐标（容差 0.01 mm）+ 同层 + 同网络 + 同尺寸的对象是否已存在"，存在就跳过。

## 2　阶段与核对门槛（整套新做时；差量修改按需要挑）

| 阶段 | 做什么 | 核对门槛（不满足就停） |
|---|---|---|
| P0 连接盘点 | app_ping；记录元件、过孔、多边形数、规则（含是否启用）、层、工程实际引用的文档 | 数量和数据包 meta 里的"现状"一致 |
| P0.1 校准 | 读校准元件位置，算 (dx, dy)，用其余参考验证；核对角度 | 误差 < 0.5 mil；角度一致 |
| P0.2 试操作 | 板外空地放 1 个过孔、1 段线，读回再删；没实测过的能力（转文字、隐藏位号…）各拿一个对象试 | 读回值 = 写入值；做不到的写进日志，改用说明书写好的备选 |
| P1 加库 | proj_add_document | 库数量 + N |
| P2 原理图 | 新建页、放元件、换默认封装、短线 + 网络标号 / 电源端口、编译 | **网表 100% 等于 nets.csv**（含跨页网络）；ERC 无 Error |
| P3 清场 | 按保留清单差集删对象；删铺铜；改板框（Board Shape + Mechanical 1 线 + 板区域） | 删除数量 = 期望数量 |
| P4 放元件 | `pcb_place_components` synced 模式（先放 1 个试） | 元件数 = 期望；焊盘带网络 |
| P5 摆放 | `obj_batch_modify` 精确坐标、旋转；库自带禁布区挪 Mech15 | pad_nets 逐个：位置 < 0.01 mm、网络一致；两脚无极性元件网络对调 → 转 180° |
| P6 孔径 | 只改数据包列出的元件 | 读回孔径 |
| P7 规则 | 只加 / 改列出的规则 | 读回 descriptor；工具改不了的留给人 |
| P8 过孔 | `pcb_place_vias`（带网络） | 数量、位置、网络、尺寸逐个一致 |
| P9 走线 | `pcb_place_tracks`（按 track_no 顺序） | 逐段几何匹配（不分方向） |
| P10 铺铜 | 放多边形 → 按层 `obj_modify` 设属性 → 重铺 | DRC 的 Un-Routed Net = 0 |
| P11 缝合孔 | 照 `stitch_vias.csv` 放 → 临时规则 → DRC → **只删表里**出问题的孔（超过 20 个就停）→ **删除**临时规则 | 放下数 = 表行数；必须存在的过孔全在；临时规则已删 |
| P12 丝印 | 藏位号（挪 Mech13）、挪封装自带 Top Overlay 文字、摆关键位号、放功能字 | 读回位置 / 字高 / 线宽 / 旋转；临时开丝印规则跑 DRC，新字 0 违规；关回后读 descriptor 带 (Disabled) |
| P13 DRC | 跑 DRC，读报告文件 | 关键项全 0；只修本次新加的对象，原有部分只记录 |
| P14 保存输出 | app_save_all；有 OutJob 再出 Gerber | still_dirty = 0 |

## 3　报告模板（AGENT_REPORT.md / 子代理汇报）

1. 第一行：成功 / 部分完成 / 失败
2. 完成到哪个阶段（最后一个 DONE），改的是哪个文件
3. 校准偏移和验证误差
4. 每阶段核对数字（期望 / 实际）
5. DRC 汇总（每条规则违规数，报告文件路径和时间）+ 未处理违规清单
6. 跳过 / 失败的步骤：工具名、参数、报错原文
7. 临场换的办法：原计划是什么、实际怎么做、效果有什么不同
8. 需要人确认的事项（附坐标）
9. 推断单独列，标明"推断"
