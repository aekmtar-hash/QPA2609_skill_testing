# 射频链路板：每个数怎么来、怎么算、怎么核对

适用：组里的射频单器件测试板 / 链路模块（4 层，顶层 50 Ω 微带线，板边 SMA），以及在这种板上用 AI + eda-agent 加电路、改丝印、打孔。数字以 QPA2609 板为例；依据文件在 `examples/qpa2609/design_basis/`（统一设计标准草案、厚度阻抗线宽说明、偏置供电说明）。

每一节都按"**定什么 → 怎么算 → QPA2609 的值 → 怎么核对**"写。标【手册】的来自器件手册或官方评估板，标【判断】的是自己定的。

---

## 1　坐标、单位、校准（每次动 AD 之前）

- 设计坐标：mm，原点 = 板左下角（AD 用户原点）。数据表同时给 `*_mil = mm / 0.0254`（保留 3 位小数）。
- eda-agent：mil，**绝对坐标**。所以开工先校准：
  ```
  读 U1 位置 (X, Y)          → DX = X − U1_x_mil，DY = Y − U1_y_mil
  用 J3、J1（带角度 90）验证 → |读回 − (数据 + 偏移)| < 0.5 mil，角度一致
  QPA2609：U1 读 (5255, 2983)，U1_mil = (500.000, 1248.031) → DX = 4755.000，DY = 1734.969
  ```
  0.031 mil 的零头来自 31.70 mm = 1248.031 mil，而 AD 里存的是 1248 mil，可以忽略。
- 之后：写入 = 数据 + 偏移；读回 − 偏移再比。原理图坐标（图纸 mil）**不加**偏移。
- 角度：AD 的 Rotation，逆时针为正。元件 Location = 封装原点（不一定是中心：3296W 在 3 脚、HDR1X2 在 1 脚）。
- 核对门槛：校准 < 0.5 mil；元件 / 焊盘读回 < 0.01 mm；过孔、文字 < 1 mil；"白名单"匹配容差 2 mil（第二轮）。

## 2　叠层 → 50 Ω 线宽（统一标准的核心）

**定什么**：射频介质的材料和厚度 h。h 和 Dk 定了，50 Ω 的线宽 W 就只有一个答案，所以"统一线宽"其实是"统一叠层"。

| 层 | 材料 | 厚度 |
|---|---|---|
| Top | 铜 1 oz | 0.036 |
| 介质 1 | **RO4003C，Dk 3.55，Df 0.0027** | **0.203 mm（决定线宽）** |
| GND2 | 铜（完整地，射频参考） | 0.036 |
| 介质 2 | FR-4 | 0.200 |
| GND3 | 铜 | 0.036 |
| 介质 3 | FR-4 | 1.000（只为凑厚度） |
| Bottom | 铜 | 0.036 |
| 成品 | | **1.566 mm（AD 显示 61.636 mil）**，配 Cinch 142-0761-851（要求 0.062 in） |

**怎么算**：AD 层叠管理器 → Impedance → Single、Target 50 Ω、Top 层参考 GND2 → **W = 16.422 mil = 0.417 mm，50.01 Ω**（盖阻焊）。
- 射频线开窗不盖阻焊后用公式重算约 50.4 Ω，差不到 1 Ω，不改线宽。
- 板厂按 Dk 3.38 做：0.417 约 51.5 Ω，影响小；换板材 / 厚度就必须重算，**全组同步改**。
- 反例（为什么要统一叠层）：同样 0.417 的线画到 0.254 mm RO4350B 上约 56 Ω，那种叠层 50 Ω 要约 0.52 mm。两块板串起来，接口处就是阻抗台阶。

**线两侧地铜 G = 1.0 mm**：约 5 × h，地铜基本不影响阻抗（官方板约 1.6 mm，改成 1.0 约差 1 Ω）。用规则 `RF_to_Pour`（射频网络 ↔ InPolygon ≥ 1 mm）保证。

**到芯片引脚前收窄**：引脚焊盘只有 0.25 mm 宽；0.25 mm 的线约 67 Ω，所以宽线一直拉到引脚跟前，**最后约 0.3 mm 才收窄**。QPA2609：宽线拉到 x = 10.45（输出侧 14.95）。14 GHz 粗算：细段 1.3 mm 回损约 15 dB，缩到 0.3 mm 约 29 dB。【对照官方评估板 Gerber】

**连接器焊盘** 0.406 mm（Cinch 推荐，约 50.6 Ω），和 0.417 只差 0.011，不改封装。

**核对**：叠层总厚 61.636 mil；Impedance 里 W = 16.422 mil / 50.01 Ω；射频线主体 0.417；`RF_Width` 规则 0.2 / 0.417 / 0.417。算出来不是 16.422 → 叠层哪一格填错了，回去逐格对表，**不要改线宽去凑**。

## 3　射频线屏蔽孔（fence）

**定什么**：线两侧各一排接地孔，孔 0.25 / 焊盘 0.5，离线中心 1.61 mm，间距 ≤ 0.6 mm。

**间距怎么算**：最高关心频率时板材里波长的 1/20。
```
λ0 = c / f = 300 / 14 GHz = 21.4 mm
λ  = λ0 / √εr = 21.4 / √3.55 = 11.4 mm      （用 εr 而不用 εeff，偏保守）
λ/20 = 0.57 mm  → 取间距 ≤ 0.6 mm（QPA2609 实际 0.6；官方板 0.554）
```

**离线中心 1.61 mm 的核对**：孔焊盘边到线边 = 1.61 − 0.25（焊盘半径）− 0.2085（半线宽）= 1.15 mm ≥ G = 1.0，孔不会落进 1 mm 的缝里。

**QPA2609 数量**：RFIN 14、RFOUT 14、THRU 46（`keep_existing_vias.csv` 的 `fence *`）。改板时属于"必须保留"，任何删除前先排除。

## 5　接地缝合孔（stitching）

**为什么自己算、不用工具自动打**：`pcb_place_stitching_vias` 的间距参数对所有对象生效，填 1 mm 就离每个焊盘、每根线都 1 mm，孔又稀又不错行，还会打进焊盘。

**算法**（`stitch_layout.py`；结果 `stitch_vias.csv`）：
```
网格：1.5 mm，隔行错开半格（0.75 mm），起点 (1.2, 1.2) mm      【官方板孔距中位数约 1.5 mm】
孔：0.25 / 0.5 mm，GND，Top→Bottom
对每个格点 P，保留条件（全部满足）：
  离射频线铜边 ≥ 1.0 mm（+ 孔半径）           ← 和 RF_to_Pour 同一个数，孔不进缝
  离任何非 GND 的铜（所有层，含原有设计的全部走线）≥ 0.2 mm（+ 孔半径）
  离已有过孔中心 ≥ 0.75 mm（孔到孔规则 0.254 只要 0.504）
  不在焊盘、元件外框、丝印字、连接器区、芯片区内；离板边 ≥ 0.75 mm
  差量修改时：对"设计模型"和"实际做成的模型"都满足
```
**核对**：
- 和原设计比密度：原 51.4 mm 板范围内原来 333 个，新算 316 个 → 同一水平（用户一眼能看出"变稀了"）。
- 执行端照表放 → 加**临时**规则 `RF_to_Via`（射频网络 ↔ IsVia ≥ 1 mm）→ DRC → 只删表里出问题的孔（> 20 个就停）→ **删除**临时规则（只禁用的话 DRC 照样算）。
- 预告"噪声"：RF_to_Via 会命中原有屏蔽孔（第二轮 84 条），说明书里写明数量，让执行端知道不用管。

**第二轮漏掉的**：只把"新走线 + 射频线"当障碍，原板上的 VG 供电线没进模型 → 一个孔离它 0.025 mm（差点短路）。**所有原有的铜都要进模型。**

## 6　模块切口和接口（拼成整条链路用）

```
测试板： [SMA + 过渡段] ─┤接口面├─ 模块区（器件 + 周边全部）─┤接口面├─ [过渡段 + SMA]
             删掉                     整块搬到整板                       删掉
```
| 项 | 值 |
|---|---|
| 接口面 | 离板边 6.00 mm（QPA2609：x = 6.0 和 19.4，离芯片中心各 6.70 mm；SMA 金属脚只到 4.55 mm） |
| 接口面上的线 | 标准线：0.417、两侧 G = 1.0、屏蔽孔连续 |
| 模块区 | 器件、去耦、底部焊盘孔、收窄段、屏蔽孔、开窗——整板上按相同相对坐标照搬 |
| 方向 | 输入在左、输出在右，一条水平直线 |
| 直流线 | 只从模块上、下两边引出，不横穿射频线（VD 往上、VG 往下） |
| 供电元件 | 全部在两条切口之间（拼板时整条切下来就是"器件 + 自己的供电"） |

**直流线必须穿过射频线时**（QPA2609 的 VG 从上方供电区到下方）：走 GND3（第 2 内层），**不走 GND2**（GND2 是射频线的参考地，必须完整）。在芯片右侧和 RFOUT 第一个屏蔽孔（15.80, 30.09 / 33.31）之间的缝里穿过，离两边孔各 0.20 mm，不拆屏蔽孔。

## 8　偏置供电（VD / VG）怎么算（QPA2609 方案一：12 V → LTC3260 ±5 V → LT3094 出 VG、LT3045 出 VD）

| 量 | 公式 | 取值 | 结果 | 依据 |
|---|---|---|---|---|
| +5 V（LTC3260 LDO+） | 1.2 V × (1 + R上/R下) | 316 k / 100 k | +4.99 V | 【手册 ADJ+ = 1.2 V】 |
| −5 V（LDO−） | −1.2 V × (1 + R上/R下) | 316 k / 100 k | −4.99 V | 【手册】 |
| VG（LT3094） | −100 µA × R_SET | 2.0 k + 0～10 k 电位器 | −0.20 ～ −1.20 V；电位器 +10% 最坏 −1.30 V，不超 QPA2609 极限 | 【手册】 |
| VG 最小负载 | 输出 0～−1.5 V 时 ≥ 10 µA | 加 10 kΩ 到地 | −0.2 V 时 20 µA | 【LT3094 Note 16】 |
| VD（LT3045） | 100 µA × R_SET | 36.0 k | 3.60 V | 【手册】 |
| VD 限流 | 150 mA·kΩ / R_ILIM | 604 Ω | 约 248 mA | 【手册】 |
| VD 开启门槛（EN/UV） | 1.24 V × (1 + 100 k / 15.0 k) | 100 k / 15.0 k | 开约 9.5 V，关约 8.5 V（回差 130 mV） | 【手册门限 1.18～1.32 V】；12 V 经二极管约 11.6 V，低 5% 也能开 |
| 测流电阻压降 | I × R | 1 Ω，120 mA | 0.12 V，芯片拿到约 3.48 V | 【判断】 |
| LT3045 前串 22 Ω / 2 W | 分担压降 | | LT3045 约 0.6～0.7 W，22 Ω 0.3～1.4 W | 【手册热阻 33 °C/W】 |
| 上电顺序 | VG 先、VD 后 | LT3094 PG 门限 −300 mV + 负压门卫 Q101/Q102 | VG 没到 −0.3 V 时 VD 不开 | 【手册 + 判断】 |

**第一次上电**：J3 接 30 Ω / 1 W 当假负载（3.6 V / 30 Ω ≈ 120 mA）先调供电，确认 VG 范围和上电顺序，再焊 QPA2609。

**布局约束**：供电元件全在切口之间；LT3045 底部焊盘下打散热孔连内层地；22 Ω 电阻和 LT3045 离放大器远一点；VD / VG 进射频部分前加磁珠 + 100 nF。

## 10　数据怎么生成、核对门槛怎么定

```
坐标源（pmod.py：元件位置 + 走线点 + 过孔）
  → 自检 check()：第 7 节全部为 0 才往下
  → 出图逐块看
  → 导出：components / nets / pad_nets / vias / track_segments / keep_existing_vias / module_design.json
  → 缝合孔、丝印、原理图坐标各自的脚本
  → ops.jsonl（每条带 params / verify / on_fail）+ 说明书
```
- **期望数量**全部从数据算出来写进 `meta.expected_counts` 和每条 op 的 `verify`，执行端只比"相等 / 不相等"。
- **删除数量**用差集算：全部过孔 − 白名单 = 正好 N 才删。
- 改了坐标源，**所有**输出重新生成（指南、数据、清单、图、包），不手改某一张表。
